# Wiki del proyecto

## Objetivo
`estadio-web` es la web editorial del libro del Estadio de Gran Canaria.

## Ruta oficial de trabajo
`/Volumes/RAID/Repos/web/estadio-web`

## Rama de trabajo
`dev`

## Naturaleza del proyecto
Es una web de contenido e imagen. Aquí importa tanto respetar el material editorial como no romper la navegación o el estilo existente.

## Estructura útil
- `index.php`: entrada principal
- carpetas temáticas como `genesis/`, `prologos/`, `metamorfosis/`, `seleccion/`
- `include/`: piezas compartidas
- `css/` y `js/`: presentación e interacción
- `img/` y `download/`: material visual y descargables

## Reglas de trabajo
- No tocar el contenido histórico sin criterio editorial
- Evitar refactors agresivos
- Modernizar de forma gradual
- Mantener compatibilidad de enlaces y rutas existentes

## Qué conviene documentar mejor
- Mapa de secciones
- Flujo de publicación
- Dependencias reales del hosting
- Política de imágenes y PDFs

## Siguiente mejora recomendada
Crear una guía de contenidos y otra de mantenimiento técnico ligero.
